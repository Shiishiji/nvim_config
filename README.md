## Git blame toggle

Functionality provided by [f-person/git-blame.nvim](https://github.com/f-person/git-blame.nvim?tab=readme-ov-file)

`:GitBlameToggle` - for toggle

`:GitBlame[Enable|Disable]`  - enable / disable
